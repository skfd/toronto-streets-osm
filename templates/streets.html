Filter rules

How TCL and OSM are filtered before joining by normalized street name.

OSM side

An OSM way is kept if all hold:

  • name=* is set
  • Centroid lies inside the City of Toronto polygon
  • highway is one of:
{% for t in rules.osm_highway_kept %}{{ t }}{% endfor %}

Liberal include: any tag where OSM could plausibly label a TCL drivable road. Excludes ramps (*_link), rec trails (cycleway), and inherently-undrivable types (steps, busway, bus_stop, bridleway, corridor, platform).

TCL side

A TCL feature is kept if FEATURE_CODE_DESC is one of:

{% for c in rules.tcl_feature_codes_kept %}{{ c }}{% endfor %}

Excludes Trail, Walkway, Busway, Railway, River, Hydro Line, Shoreline, Creek, Ferry.

Match key

normalize_street(name) — e.g. "Yonge Street" and "Yonge St" both become YONGE ST.
